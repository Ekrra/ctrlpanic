# Ctrlpanic

Build and design a complete, functional web application called CtrlPanic, an AI-powered Python debugging tutor for beginner programmers and competitive programming students. The concept is to help students understand programming errors instead of simply copying corrected code. Make the website feel like a thoughtfully designed, premium indie tech product with a subtle Gen Z personality: cute, clever, calming, slightly humorous, and professional enough to impress judges at the YUNet AIgnite 2026 buildathon. Use a muted, sophisticated palette of warm cream, dusty cerulean blue, soft blue-gray, and understated butter yellow, with dark blue-gray text. Keep the interface calm and visually balanced rather than bright, neon, childish, or excessively decorative. Create an original, adorable mascot logo: a tiny, expressive computer character with little hands, a slightly panicked face, and a small keyboard-inspired detail. Give it a distinctive illustrated 2D style, clean outlines, and a memorable silhouette that works as both a website logo and a small app icon. Make the mascot expressive and charming without looking like a generic robot. Build a complete homepage with a clean navigation bar featuring the logo, CtrlPanic wordmark, How It Works, Features, and Get Started links. The hero section should have a strong headline reading “Code not working?”, followed by “Ctrl your panic. Fix your code.” and a short explanation that the tool helps students understand and fix Python errors without the stress. Include a prominent “Explain My Error” call-to-action. Below the hero, create an interactive debugging workspace with a Python code editor that supports pasting and editing code, an optional field for the error message, selectable beginner-friendly examples, and a clear button to analyze the code. When a student submits code, display a well-organized results panel containing the detected error type, the relevant line of code when identifiable, a simple English explanation, why the error happened, corrected code with syntax highlighting, a copy-code button, and a step-by-step explanation of the correction. Include a small practice section with a related question to help students learn from their mistakes. Add a feature section explaining simple error explanations, step-by-step fixes, beginner-friendly learning, and less stressful debugging; a How It Works section with three steps; a few realistic example scenarios; and a clear footer. Use subtle animations, smooth transitions, carefully spaced layouts, rounded cards, delicate borders, restrained shadows, and selective translucent surfaces. Give the mascot a few small contextual expressions, such as looking confused when code contains an error and happy when a fix is explained. Keep jokes short and friendly, such as “Oops, Python found something suspicious” or “Bestie, this line needs a colon,” without insulting or embarrassing students. Make every visible button and navigation link functional, include loading states, empty-input validation, useful error messages, and a reset option, and ensure the entire website is responsive and accessible on phones and computers. Use a real code editor component if practical rather than an ordinary text box. Most importantly, implement genuine AI-powered debugging through a secure server-side API integration that analyzes submitted Python code and returns structured explanations. Never expose API keys in frontend code, never pretend sample responses are real AI analysis, and clearly distinguish any demo examples from actual results. If API credentials are not configured yet, create the interface and integration structure honestly, with a clear setup requirement rather than a fake working AI feature. Keep the code organized, maintainable, and suitable for further development. Build this as a cohesive, polished, usable product rather than a static landing-page mockup, and preserve any useful existing functionality in my current project instead of unnecessarily rebuilding everything from scratch.
